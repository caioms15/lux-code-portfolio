Substitua os placeholders SVG por fotos reais quando disponíveis. Manter os mesmos
nomes de arquivo (ou atualizar as referências em `landing-page/index.html`).

- `foto-retrato-cristal-tower.svg` → foto sorrindo de camisa branca, "Cristal Tower" ao fundo (usada na seção Sobre o professor).
- `foto-sala-aula.svg` → foto ensinando em sala de aula com alunos (usada como imagem de apoio/fundo).
- `foto-bolo-comemorativo.svg` → foto comemorativa em frente ao quadro (uso opcional, prova social/bastidores).
- `logo-perfil.svg` → foto de perfil / avatar usado no Instagram.
